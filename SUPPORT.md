# Support

This repository provides community-maintained educational material, not a
service-level agreement or production support contract.

## Where to ask

- Open a **lesson verification** issue when a command, UI label, expected
  result, platform, or package version does not reproduce.
- Open a **bug report** for a course-owned project, plugin, validator, or
  workflow defect.
- Use the upstream DeepSeek Harness repository when the issue reproduces in
  upstream software without course-owned code or instructions.
- Follow [SECURITY.md](SECURITY.md) instead of opening a public issue for a
  vulnerability or sensitive finding.

## Include enough evidence

Provide the module and path, course commit, exact DSH package, immutable
upstream reference, operating system and architecture, Node and package-manager
versions, commands run, expected result, observed result, and the smallest
synthetic reproduction.

Redact credentials, private prompts, customer data, home-directory names,
private repository identifiers, and Session contents that are not necessary to
understand the defect. Prefer a newly created synthetic fixture over a redacted
production repository.

## Response expectations

Maintainers may ask for a clean reproduction, close reports that belong
upstream, or defer work that does not affect the active English edition. The
current priority is English v1 verification; Simplified Chinese and Japanese
localization remain frozen until that milestone is complete.
