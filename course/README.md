# Course Editions

English is the canonical source. Simplified Chinese and Japanese follow the same module numbers, learning outcomes, runnable artifacts, and upstream verification references.

| Edition | Entry point | Role | Current state |
|---|---|---|---|
| English | [course/en/](en/) | Canonical content | Curriculum ready |
| 简体中文 | [course/zh-CN/](zh-CN/) | Translation | Structure ready |
| 日本語 | [course/ja/](ja/) | Translation | Structure ready |

## Publishing order

For each module:

1. Draft the English lesson.
2. Verify commands and artifacts against an immutable upstream reference.
3. Mark the English lesson verified.
4. Translate into Simplified Chinese.
5. Translate into Japanese and complete native-language review.
6. Recheck shared code and links from every edition.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for translation rules and [docs/VERSIONING.md](../docs/VERSIONING.md) for verification requirements.
