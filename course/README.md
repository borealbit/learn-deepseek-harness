# Course

English is the only active edition during the initial build. The course will be localized only after the English v1 lessons, commands, labs, and safety guidance are complete and verified.

| Edition | Entry point | Current state |
|---|---|---|
| English | [course/en/](en/) | Active — Modules 00–06 draft |
| Simplified Chinese | `course/zh-CN/` | Frozen placeholder |
| Japanese | `course/ja/` | Frozen placeholder |

## Current publishing order

1. Research the current upstream source and installable package.
2. Draft the English lesson and its runnable artifact.
3. Execute the lesson on the declared platforms.
4. Record an immutable source reference, package version, date, and evidence.
5. Mark the English lesson verified only after all required checks pass.
6. Move to the next English module.

Localization is deferred until the English v1 milestone. See [CONTRIBUTING.md](../CONTRIBUTING.md) and [docs/VERSIONING.md](../docs/VERSIONING.md) for the contribution and verification rules.
