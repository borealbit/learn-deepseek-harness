## 翻译原则

- 保留代码、标识符、文件路径和 API 名称。
- 使用中文解释概念，但避免创造与上游不一致的新术语。
- 英文内容发生变化时，受影响的中文章节会标记为 `needs-review`。
- 技术验证和中文审校全部完成后，才能标记为 `verified`。
