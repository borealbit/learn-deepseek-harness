## 翻訳方針

- コード、識別子、ファイルパス、API 名は原則として維持します。
- 逐語訳ではなく、技術的な意味と学習成果を保ちます。
- 英語版の変更後は、該当モジュールを `needs-review` とします。
- 技術レビューと自然な日本語のレビューが完了するまで `verified` にしません。
