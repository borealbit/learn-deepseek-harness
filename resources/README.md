## Curation rules

- Link to the canonical source when available.
- Record access or verification dates in technical reviews.
- Distinguish observed behavior from interpretation.
- Do not copy large sections of upstream documentation.
- Do not list a third-party plugin as recommended until its permissions and maintenance state have been reviewed.
